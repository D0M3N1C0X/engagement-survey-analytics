# Data dictionary

Four files, generated by [`../src/generate_survey.py`](../src/generate_survey.py) with seed
`7`. Regenerating produces byte-identical files on any Python 3.10+.

- **Survey:** Voice 2026, fieldwork 4-22 May 2026
- **Population:** 3,800 invited employees, 149 teams, 4 countries, 6 departments
- **Responses:** 2,753 (72.4%), of which 879 left at least one comment
- **Instrument:** 22 driver items across 8 dimensions, 3 outcome items, 1 eNPS question

---

## `survey_responses.csv` - one row per **invited** employee

Non-respondents are included with empty answer columns. Response rate and non-response bias
are part of the analysis, so the invite list has to be in the data.

| Column | Type | Description |
|---|---|---|
| `response_id` | text | Primary key, `R00001` format |
| `team_id` | text | Foreign key to `teams.csv` |
| `department` | text | Operations, Customer Service, Commercial, Technology, Finance & Legal, People & Workplace |
| `country` | text | `IT`, `PL`, `DE`, `ES` |
| `job_level` | text | Individual contributor, Team lead, Manager, Senior leader |
| `tenure_band` | text | `< 1 year`, `1-2 years`, `3-5 years`, `6-10 years`, `10 years +` |
| `work_model` | text | Onsite, Hybrid, Remote |
| `shift_worker` | integer | 1 where the role is shift-based |
| `responded` | integer | 1 if the employee completed the survey |
| `submitted_date` | date | Date of submission, empty for non-respondents |
| `enps` | integer | 0-10 recommendation score, empty for non-respondents |
| `mgr_01` … `tls_02` | integer | 22 driver items, 1 (strongly disagree) to 5 (strongly agree) |
| `eng_01` … `eng_03` | integer | 3 outcome items on the same scale - the engagement index |

| Column | Type | Description |

| `wording` | text | The question as the employee saw it |

## `teams.csv` - the team roster

| Column | Type | Description |
|---|---|---|

## `comment_themes_truth.csv` - labels, for evaluation only

| Column | Type | Description |
|---|---|---|
| `comment_id` | text | Foreign key to `survey_comments.csv` |
| `true_themes` | text | Semicolon-separated themes the verbatim was built from |
| `true_tone` | text | `positive` or `negative` |

This file is a luxury no real project has: it exists so the keyword tagger and the sentiment
scorer can be **measured** rather than admired. `src/analysis_text.py` reports precision,
recall and F1 against it before quoting a single theme. On real data the equivalent is a
hand-labelled sample of a few hundred comments, and the report describes that protocol.

## What is deliberately planted in the data

A generator producing pure noise would make the analysis meaningless; one producing textbook
effects would make it dishonest. These are the mechanisms built in, stated openly so the
analysis can be judged on whether it recovers and sizes them correctly:

| Mechanism | How it is built | Where it should show up |
|---|---|---|
| **True driver weights** | Engagement is a weighted sum of the eight dimensions - Manager Support 0.26, Career Growth 0.22, Recognition 0.15, Workload 0.12, Leadership 0.10, Pay 0.06, Inclusion 0.06, Tools 0.03 | The relative weight analysis, which has to recover this order from correlated predictors |
| **Priority quadrant** | Career Growth and Recognition are set to score low while carrying high weight; Pay scores low and carries little weight | The impact-vs-performance map, and the argument about pay |
| **Manager effect** | Every team has a latent manager quality that moves Manager Support strongly and Recognition and Career Growth moderately | The spread between teams, and the coaching list |
| **Non-response bias** | Response probability falls with disengagement, shift work and being in Operations | The participation section - respondents are a rosier sample than the workforce |
| **Comment mix** | Disengaged people write more critical comments and fewer positive ones; the closing sentence of a complaint hardens as engagement drops | Sentiment correlating with the writer's own eNPS |
| **Theme vocabulary** | Verbatims are assembled from theme-specific phrasing, with about a fifth carrying a second theme | Multi-label tagging, and the false positives the evaluation reports |
| **Seasoned segments** | Country, department, level and tenure each shift the dimensions a little | The heatmap having real structure rather than noise |

Noise is applied on top of every mechanism, and the response scale is coarse (five points),
which is why some effects come out clean and others honestly do not.

## A note on ethics

Everything here is synthetic, but the analysis is written as if it were not: no result is
published for a group below five respondents, no verbatim is quoted from a small group, no
inference is made about an individual, and comments pass through a redaction step before
being shown. Those rules cost very little to implement and they are the entire reason
employees answer the second survey.
